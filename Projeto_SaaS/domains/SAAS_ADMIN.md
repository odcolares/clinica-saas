# SAAS_ADMIN.md — Administração SaaS v1.0

## Escopo
Administração global da plataforma, separada da administração interna de cada Tenant.

## Objetos
Tenant, plano aplicado, configurações globais, API keys administrativas e AuditLog.

## Capacidades
- Criar/ativar/suspender tenant.
- Consultar saúde e uso.
- Administrar configurações globais.
- Gerenciar limites derivados do plano.
- Auditar ações administrativas.

## Regra
Admin de um tenant não recebe privilégios de SaaS Admin automaticamente.
